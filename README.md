# A-Maze-ing

## Description

設定ファイルを読み込んで迷路を生成し、16進数の壁情報としてファイルに書き出し、ターミナルに表示するプログラムです。迷路の生成部分は `mazegen` パッケージとして切り出してあり、他のプロジェクトから再利用できます。

- `PERFECT=True` のときは、入口から出口までの道が1本だけの完全迷路を作ります
- `PERFECT=False` のときは、ループがあり行き止まりのほとんどない、パックマン風ゲームの盤面として使える迷路を作ります（四隅と中心は必ず通路）
- どちらのモードでも、四方を壁で囲まれたセルで迷路の中に「42」の模様を描きます。迷路が小さすぎて描けないときは、メッセージを出して模様なしで生成します
- 同じ `SEED` を指定すれば、同じ迷路を再現できます

## Instructions

### 必要なもの

- Python 3.10 以上

### インストール

```sh
make install
```

`.venv/` に仮想環境を作り、`requirements.txt` の開発用ツール（flake8 / mypy / pytest / build）を入れます。

### 実行

```sh
make run
# または
python3 a_maze_ing.py config.txt
```

設定ファイルが見つからない、書き方が間違っている、値が範囲外（入口・出口が迷路の外、入口と出口が同じ、サイズが 0 以下など）の場合は、理由を表示して終了します。

### Makefile のルール

| ルール | 内容 |
|---|---|
| `make install` | 仮想環境を作って依存パッケージを入れる |

## 設定ファイル

1行に1つ `KEY=VALUE` の形で書きます。`#` で始まる行はコメントです。同じキーを2回書くとエラーになります。

| キー | 必須 | 説明 | 例 |
|---|---|---|---|
| `WIDTH` | ○ | 迷路の横幅（セル数） | `WIDTH=20` |
| `HEIGHT` | ○ | 迷路の高さ（セル数） | `HEIGHT=15` |
| `ENTRY` | ○ | 入口の座標 `x,y` | `ENTRY=0,0` |
| `EXIT` | ○ | 出口の座標 `x,y` | `EXIT=19,14` |
| `OUTPUT_FILE` | ○ | 出力ファイル名 | `OUTPUT_FILE=maze.txt` |
| `PERFECT` | ○ | 完全迷路にするか（`True` / `False`） | `PERFECT=True` |
| `SEED` | | 乱数のシード。同じ値なら同じ迷路になる。省略すると毎回ランダム | `SEED=42` |

座標の `x` は横方向（左が 0）、`y` は縦方向（上が 0）です。リポジトリにはデフォルトの設定ファイル `config.txt` があります。

```
WIDTH=20
HEIGHT=15
ENTRY=0,0
EXIT=19,14
OUTPUT_FILE=maze.txt
PERFECT=True
```

## 出力ファイル

1セルを16進数1桁で表し、1行が迷路の1行に対応します。各ビットは壁が閉じているかどうかを表します（閉じていれば 1）。

| ビット | 方角 |
|---|---|
| 0（1） | 北 |
| 1（2） | 東 |
| 2（4） | 南 |
| 3（8） | 西 |

例えば `9`（1 + 8）は北と西に壁があるセル、`F` は四方が壁のセル（「42」の模様）です。

迷路の後に空行を1行入れ、入口の座標、出口の座標、入口から出口までの最短経路（`N` / `E` / `S` / `W` の並び）を1行ずつ書きます。

## 画面の見方と操作

迷路を Unicode の罫線で表示します。

| 表示 | 意味 |
|---|---|
| `S`（マゼンタ） | 入口 |
| `G`（シアン） | 出口 |
| `█`（グレー） | 「42」の模様のセル |
| `━` `┃` `┏` など（オレンジの太線） | 最短経路（表示をオンにしたとき） |

表示の下にメニューが出るので、番号を入力して Enter を押します。

| 入力 | 操作 |
|---|---|
| `1` | 新しい迷路を生成して表示する（毎回違う迷路になる） |
| `2` | 最短経路の表示 / 非表示を切り替える |
| `3` | 壁の色を切り替える（白 → 赤 → 緑 → 黄 → 青） |
| `4` | 終了する |

Ctrl-D / Ctrl-C でも `4` と同じように終了します。「42」の模様の色は、壁の色を切り替えても変わりません。

## 迷路生成のアルゴリズム

穴掘り法（ランダム化した深さ優先探索 / recursive backtracker）を使っています。

1. すべてのセルを四方が壁の状態で用意し、「42」の模様のセルに印を付ける（模様のセルは最後まで壁に囲まれたまま）
2. 入口から始めて、まだ訪れていない隣のセルをランダムに選び、間の壁を壊して進む
3. 進める隣がなくなったら1歩戻り、また別の隣を探す。スタックが空になるまで続ける。これで全セルが1本の木でつながった完全迷路になる
4. `PERFECT=False` のときは、行き止まりのセルの壁をさらに壊してループを作る。このとき 3x3 の開けた空間ができないことを確認する
5. 幅優先探索（BFS）で入口から出口までの最短経路を求める

## 再利用できる部分

迷路の生成と最短経路の探索は `mazegen` パッケージにまとまっていて、他のプロジェクトから import して使えます。表示（`front.py`）と設定ファイルの読み込み（`a_maze_ing.py`）は、このプロジェクト専用です。

```sh
make build                                   # mazegen-1.0.0-py3-none-any.whl ができる
pip install mazegen-1.0.0-py3-none-any.whl
```

```python
from mazegen import Mazegenerator

maze = Mazegenerator(20, 15, (0, 0), (19, 14), "maze.txt", seed=42, perfect=True)
maze.maze_gen()

cell = maze.grid[0][0]               # 座標 (x, y) のセルは maze.grid[y][x]
cell.north, cell.east                # True なら壁がある
path = maze.find_shortest_path()     # 入口から出口までの座標のリスト
maze.write_to_file()                 # 上の形式でファイルに書き出す
```

パラメータの一覧など、詳しい使い方は [mazegen/README.md](mazegen/README.md) にあります。

## 追加した機能

- 最短経路を、点ではなくつながった線で描く
- 入口・出口・「42」の模様を、壁とは別の色で表示する
- `PERFECT=False` の迷路は、課題付属の `maze_analyzer.py` で行き止まりなし（no real dead-end）と判定される

### 計画と進め方

- 最初に、表示（フロント）と迷路生成（バックエンド）で担当を分けた
- 座標は外から見える値をすべて `(x, y)` で統一し、配列へのアクセスは `maze[y][x]` とすることを最初に決めた。設定ファイルの `ENTRY=x,y` / `EXIT=x,y` とも揃う
- 表示は、MiniLibX ではなくターミナルの ASCII 表示にする方針にした
- まず生成から表示まで動くものを作り、パッケージ化（`mazegen`）は最後にまとめて行う方針で進めた
- GitHub の Pull Request でお互いのコードをレビューしてからマージした（PR #1 表示、PR #2 迷路生成、PR #3 表示の改善とつなぎ込み、PR #4 パッケージ化）

### うまくいったこと・改善できること

うまくいったこと：

- Pull Request でお互いのコードをレビューし合うようにしたので、マージ前に不具合や課題の要件とのずれに気づけた
- 座標の扱いなどのルールを最初に決めておいたので、表示と生成をそれぞれ並行して進められた

苦労したこと・改善できること：

- それぞれが別々に開発したので、相方のコードを理解するのに少し時間がかかった。次は、途中の段階でもこまめにコードを共有したり、関数の使い方を先に決めておいたりすると、つなぎ込みがスムーズになりそう
